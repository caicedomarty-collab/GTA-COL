# Colombia GTA - Ciudad Natal 3D

## Descripción
Juego de mundo abierto 3D estilo GTA (Grand Theft Auto) ambientado en una ciudad colombiana. Corre directamente en el navegador usando Three.js, optimizado para PCs con especificaciones modestas.

## Características
- **Mundo 3D abierto** con ciudad colombiana
- **100 misiones** (principales y secundarias)
- **Historia** de un joven que regresa a su ciudad natal
- **Vehículos** para conducir
- **Gráficos 3D** estilo GTA Vice City/San Andreas
- **Optimizado** para Intel Core i3 + gráficos integrados

## Requisitos
- **Navegador web** (Chrome, Firefox, Edge, Safari)
- **Conexión a internet** (para cargar Three.js)
- **PC**: Intel Core i3, 4GB+ RAM, gráficos integrados

## Instalación
1. Descarga el código o clona el repositorio
2. Abre `index.html` en tu navegador
3. ¡Juega!

## Controles
- **WASD**: Mover personaje
- **Espacio**: Saltar
- **E**: Entrar/salir vehículo
- **M**: Ver lista de misiones

## Para GitHub Pages
1. Sube todos los archivos a tu repositorio de GitHub
2. Ve a Settings → Pages
3. Selecciona "main" branch
4. Guarda - tu juego estará en `https://tu-usuario.github.io/tu-repo/`

## Tecnologías
- **Three.js**: Motor 3D para navegador
- **HTML5/CSS3**: Interfaz de usuario
- **JavaScript**: Lógica del juego
